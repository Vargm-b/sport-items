Registro de Items

Permite registrar el elemento base y los demás items según su valor relativo.

1. Registrar elemento base

Debe registrarse primero para habilitar el resto del sistema.

2. Registrar item

Seleccione un deporte e ingrese el valor correspondiente. La posición se asigna automáticamente.

3. Verificar existencia

Compruebe si un item ya fue registrado.

4. Mostrar lista registrada

La lista se mostrará ordenada por valor.
